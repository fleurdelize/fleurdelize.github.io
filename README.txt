Fleur Desk’Aid Cinematic Portfolio

Open index.html in a browser. This is a self-contained HTML/CSS/JavaScript website; the included assets folder contains the portfolio images used in the design.
It uses Google Fonts when internet access is available. The design is responsive and includes an animated loading screen, mobile navigation, scroll reveals, and an infinite marquee.
Update the images in assets/ or edit index.html to customize project samples and contact details.
